# AIDA Café Reusable Agent Prompts

These prompts are intended for fresh ChatGPT, Codex, Claude, Astra, or other coding-agent sessions.

- `FRESH_CHAT_BOOTSTRAP.md` — reconstruct project context before substantial work.
- `CUSTOMER_APP_TASK.md` — customer Flutter task without weakening shared authority.
- `DASHBOARD_TASK.md` — POS/Admin React task within the same backend contract.
- `SHARED_BACKEND_TASK.md` — Supabase/schema/RPC/RLS work.
- `CROSS_REPO_TASK.md` — coordinated change touching both repositories.
- `RELEASE_AUDIT.md` — customer/Dashboard release validation and evidence.
- `DOCUMENTATION_SYNC.md` — reconcile mirrored governance and AI context.

These are reusable starting contracts. They do not replace current code inspection, Git evidence, accepted ADRs, or live Supabase verification.
